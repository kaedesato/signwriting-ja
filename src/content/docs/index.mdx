## SignWriting の特徴

<CardGrid stagger>
	<Card title="手話のビジュアル文字体系" icon="open-book">
		話し言葉の文字が音を表すのに対し、手話の「手の形」「向き」「位置」「動き」「顔の表情」をそのまま二次元のグラフィック記号として書き表します。
	</Card>
	<Card title="あらゆる手話に対応する世界規格" icon="approve-list">
		アメリカ手話（ASL）や日本手話（JSL）など、特定の言語に依存せず、世界中のあらゆる手話言語を全く同じ記号規則（ISWA 2010）で記述できます。
	</Card>
	<Card title="Unicode との完全な互換性" icon="setting">
		Unicode 8.0にて標準ブロックとして登録。FSW（Formal SignWriting）仕様により、データベースや検索エンジンでも処理可能なテキストデータとして扱えます。
	</Card>
	<Card title="Webでのクリアな描画" icon="sun">
		公式コンポーネントを導入することで、画像アセット不要でベクター画像（SVG）として拡大縮小自在に手話文字を描画できます。
	</Card>
</CardGrid>
