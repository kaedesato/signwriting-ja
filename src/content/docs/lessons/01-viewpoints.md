手話を正確に記述するための第一歩は、**「どの視点から手話を見るか」**というルールと、**「頭部や顔のパーツをどう配置するか」**という二次元レイアウトの基礎を理解することです。

---

## 1. 表現者視点 (Expressive Viewpoint)

手話文字は、サインをしている本人が**「自分自身の両手を見おろしている視点」**で記述されます。これを**「表現者視点（Expressive Viewpoint）」**と呼びます。

    <p style="font-size: 0.95rem; line-height: 1.6; margin-bottom: 0;">
      対面で他の人がサインしているのを観察する視点は「受信者視点」と呼ばれます。しかし、SignWritingの標準表記法は<strong>「表現者視点」</strong>です。これは、自分が手話を行うときに、自分の手がどう見えているか、どう感じられているかを表します。
    </p>
  </div>

* **右手の記号**：身体の中心線（センターライン）の**右側**に配置されます。
* **左手の記号**：身体の中心線（センターライン）の**左側**に配置されます。
* **直感的な模倣**：このルールにより、読み手は文字を見たまま、自分の両手を動かすだけで正しい手話のポーズを取ることができます。

---

## 2. 手のひらの3つの向き (Palm Facings)

表現者視点において、手のひらが自分（表現者）に対してどの向きを向いているかを、手のひら記号の**「色（塗りつぶし）」**で識別します。

## 3. 頭部と顔面パーツの二次元配置 (Head & Face Placement)

頭部の記号は、表現者の頭を**後ろから透かして見た「頭部円 (Head Circle)」**というサークルをベースにします。

* **頭部円 (Head Circle)**：顔の輪郭を表す単純な円（丸） <fsw-symbol symbol="S2e300" style="transform:scale(1.0);"></fsw-symbol>。
* **パーツのレイアウト**：表現者の視点（後方からの透視図）であるため、**円の左側は表現者の左顔面、右側は表現者の右顔面**に対応します。

```
       [ 眉 / Eyebrows ]   (円の上部・枠外)
     [ 目 / Eyes ]    [ 目 / Eyes ] (円の内部・上部)
            [ 鼻 / Nose ]        (円の中心)
       [ 頬 / Cheeks ] [ 頬 / Cheeks ] (中心の左右)
         [ 口・顎 / Mouth & Jaw ] (円の下部)
```

例えば、右手の指先が右頬に触れる場合、手話文字の中では手の記号は頭部円の**右側**に配置され、接触記号が添えられます。

* **接触の記述例**：
  * **右側の接触**：頭部円の右側に手を配置 <fsw-symbol symbol="S2e500" style="transform:scale(1.0);"></fsw-symbol> + 接触記号。
  * **左側の接触**：頭部円の左側に手を配置。

---

## まとめ

1. **表現者視点**：自分の手話動作を自分自身の視点で記述する（右側＝右手、左側＝左手）。
2. **手の向き**：白＝手のひら、半黒＝側面、黒＝手の甲。
3. **頭部円マップ**：頭を後ろから透視した構図で、顔のパーツや手の位置関係を二次元的にマッピングする。
