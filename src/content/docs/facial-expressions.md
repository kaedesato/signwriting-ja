---
title: 3. 表情と頭部記号
description: 手話言語に不可欠な表情（非手指動作：Non-Manual Markers）や頭部の動きを表す記号の体系的な構造について日本語で分かりやすく解説します。
---

手話において、顔の表情や頭部の傾きは単なる「感情の表現」ではありません。疑問文、否定文、強調、関係節などの重要な**文法機能**を担う、言語として不可欠な要素です。これを**「非手指動作（NMM: Non-Manual Markers）」**と呼びます。

SignWritingでは、これらを**「頭部円 (Head Circle)」**を中心とした精緻なマップに基づいて表現します。

---

## 1. 頭部円マップの概念 (Head Circle Map)

顔の記号は、表現者の頭を後ろから透かして見た**「頭部円」**というサークルをベースにし、その中に目・眉・鼻・口などの記号（ダイアクリティック）を適切な位置に配置して描かれます。

```
       [ 眉 / Eyebrows ]  (円の上部枠外)
     [ 目 / Eyes ]   [ 目 / Eyes ]
            [ 鼻 / Nose ]
       [ 頬 / Cheeks ] [ 頬 / Cheeks ]
        [ 口・顎 / Mouth & Jaw ]
```

表現者の視点（後ろから見た透視図）であるため、**記号の左側は表現者の左顔面、右側は表現者の右顔面**に対応します。

---

## 2. 眉と目の記号 (Eyebrows & Eyes)

眉の上下や目の開閉、そして「どこを見ているか（視線）」は、以下のように直感的に記述されます。

### A. 眉の記号 (Eyebrows)
頭部円の上に、眉の形を模した細い線を描きます。
- **眉を上げる (Raise Eyebrows)**: <fsw-symbol symbol="S2e500" style="transform:scale(1.2);"></fsw-symbol> (上向きの緩やかなカーブ)
  手話での「はい/いいえ」を尋ねる疑問文（Yes/No疑問）や強調を表します。
- **眉をひそめる・寄せる (Furrow Eyebrows)**: <fsw-symbol symbol="S2e510" style="transform:scale(1.2);"></fsw-symbol> (中央が下がったV字型)
  手話での疑問詞（何、誰、どこ等）を伴う疑問文（WH疑問）や、否定、不満を表します。

### B. 目の記号と視線 (Eyes & Gaze)
- **目を大きく見開く**: 丸い円の目 <fsw-symbol symbol="S2e600"></fsw-symbol>
- **目を閉じる / 細める**: まっすぐな横線や半円 <fsw-symbol symbol="S2e620"></fsw-symbol>
- **ウィンク**: 片目を閉じる（片側だけ横線にする）。
- **視線の方向 (Gaze)**: 小さな矢印やドットを目の近くに配置し、視線が「上」「下」「左」「右」のどこを向いているかを示します。

---

## 3. 口と頬の記号 (Mouth & Cheeks)

口元は、手話の副詞的意味（例：「優しく」「一生懸命に」など）や日本語の口の形（マウシング）を補う重要な部位です。

| 表情・口の形 | 記号 | 手話での文法・副詞的意味 |
| :--- | :--- | :--- |
| **微笑む (Smile)** | <fsw-symbol symbol="S2e700" style="transform:scale(1.2);"></fsw-symbol> (上向きの半円) | 肯定的、穏やか、楽しい様子 |
| **口をすぼめる (Pucker)** | <fsw-symbol symbol="S2e730" style="transform:scale(1.2);"></fsw-symbol> (小さな丸) | 丁寧に行う様子、またはアルファベットの「O」の口型 |
| **口を開ける (Open Mouth)** | <fsw-symbol symbol="S2e710" style="transform:scale(1.2);"></fsw-symbol> (大きな楕円) | 驚き、あるいは強い肯定 |
| **頬を膨らませる (Puffed Cheeks)** | 頭部円の左右に膨らみの記号 | 「たくさん」「太い」「重い」といった程度の強調 |
| **舌を出す (Tongue Out)** | 口の記号から下へ突き出る小さな線 | 「うっかり」「やっとのことで」などの副詞的ニュアンス |

---

## 4. 頭部の傾きと首の記号 (Head Tilt & Neck)

首がどちらへ傾いているか、あるいは頭部全体がどう動くかを記述します。

- **首の傾き (Head Tilt)**:
  頭部円の下に**「首を表す斜めのバー」**を配置することで、頭が右または左に傾いていることを表します。
  - 右肩へ傾く: <fsw-symbol symbol="S2e300" style="transform:scale(1.2);"></fsw-symbol>
  - 左肩へ傾く: <fsw-symbol symbol="S2e308" style="transform:scale(1.2);"></fsw-symbol>
- **頭の動きの矢印**:
  頭部円の近くに動きの矢印を配置し、頭を「うなずかせる」「横に振る」「前に突き出す」などの物理的運動を示します（例：うなずく＝頭部円の横に下向きの二重線矢印）。

---

## まとめ

1. **頭部円（サークル）**: すべての表情記号をレイアウトするためのキャンバス。
2. **眉の重要性**: 上がる＝Yes/No疑問、ひそめる＝WH疑問・否定。
3. **口と頬**: 手話の意味を修飾する副詞的なニュアンス（大きさ、重さ、丁寧さなど）を細かく表現。
4. **首・頭の動き**: 傾きやうなずきといった、体全体の空間的イントネーションを記述。
