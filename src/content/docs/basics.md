SignWritingを読み書きするための最も基礎となる4つのルールを学びましょう。これらのルールを理解すると、記号がどのように実際の手話の動きに対応しているのかが直感的に見えてきます。

---

## Rule 1: 表現者視点 (Expressive Viewpoint)

手話文字は、サインをしている人の**「自分自身の視点（表現者視点）」**で記述するのが標準ルールです。

- **右手の記号**は、センターラインの**右側**に配置されます。
- **左手の記号**は、センターラインの**左側**に配置されます。
- このルールにより、自分が文字を読んでそのまま体を動かすだけで、自然に正しい手話のポーズを取ることができます。

## Rule 2: 3つの基本手形状 (3 Basic Handshapes)

SignWritingにおける数百種類の手の形は、すべて以下の**3つの基本形状（ルートシェイプ）**から出発し、そこに指を表す線を描き足すことで構成されています。

| 形状分類 | 記号 | 手話での意味 | 実際の例 |
| :--- | :--- | :--- | :--- |
| **握り拳 (Closed Fist)** | <fsw-symbol symbol="S10000" style="transform:scale(1.2);"></fsw-symbol> (正方形) | 指先が手のひらに強く触れている形 | アルファベットの **S** や 数字の **1** |
| **開いた拳 (Open Fist)** | <fsw-symbol symbol="S10e00" style="transform:scale(1.2);"></fsw-symbol> (円) | 指先同士が触れ合って中に丸い空間ができる形 | アルファベットの **O** や **D** |
| **平らな手 (Flat Hand)** | <fsw-symbol symbol="S14c00" style="transform:scale(1.2);"></fsw-symbol> (長方形) | すべての指がまっすぐに伸びて揃っている形 | アルファベットの **B** や 数字の **5** |

### 指を描き足す例
基本の形に指を表す線を加えることで、様々な手の形を直感的に表現します。
- <fsw-symbol symbol="S10000"></fsw-symbol> (握り拳) ＋ 上に1本の線 ＝ <fsw-symbol symbol="S10110"></fsw-symbol> **「人差し指を立てた手 (Index Hand)」**
- <fsw-symbol symbol="S14c00"></fsw-symbol> (平らな手) ＋ 横に親指の線 ＝ <fsw-symbol symbol="S14c00"></fsw-symbol> **「親指を横に張った平手」**
- <fsw-symbol symbol="S10000"></fsw-symbol> (握り拳) ＋ 5本の線 ＝ <fsw-symbol symbol="S18700"></fsw-symbol> **「5本の指を広げた手 (5-Hand)」**

## Rule 3: 手のひらの向き (Palm Facings)

手の「手のひら」「側面」「手の甲」が、サインをする自分に対してどちらを向いているかを、記号の**「色（塗りつぶし）」**で表します。

```
手のひら (白)  ➡  手の側面 (半白半黒)  ➡  手の甲 (黒)
```

## Rule 4: 空間プレーン (Planes)

SignWritingでは、空間の捉え方として**「壁プレーン（垂直面）」**と**「床プレーン（水平面）」**の2つの次元（プレーン）を区別します。これにより、手が胸の前に垂直に立っているか、テーブルと平行に水平に倒れているかを書き分けます。

### 1. 壁プレーン (Wall Plane)
- 手が**目の前の壁（または自分の胸）と平行**な状態。
- 指先は「上」「下」「左」「右」を向きます。
- 記号は通常のプレーンな状態で描かれます (例: <fsw-symbol symbol="S14c00"></fsw-symbol>)。

### 2. 床プレーン (Floor Plane)
- 手が**床や地面と平行**な状態。
- 指先は「前方（相手の方向）」や「真横」を向きます。
- 床プレーンの記号には、指の付け根に**「地平線（隙間・すきま）」**が入り、パーツが少し浮いた状態で描かれます (例: <fsw-symbol symbol="S14c10"></fsw-symbol>)。

```
【比較】
壁プレーンの平手 (指先が上、手のひらが自分): <fsw-symbol symbol="S14c00" style="transform:scale(1.3);"></fsw-symbol>
床プレーンの平手 (指先が前、手のひらが上向き): <fsw-symbol symbol="S14c10" style="transform:scale(1.3);"></fsw-symbol> (隙間がある)
```

この「地平線の隙間」という視覚的デザインにより、二次元の紙面の上でも、手が垂直に立っているか、水平に前に伸びているかが一目で区別できます。

---

## まとめ

1. **表現者視点**: 自分の手を見るように描く。
2. **3つの基本形**: 四角（握り拳）、円（開いた拳）、長方形（平手）。
3. **色の塗り分け**: 白＝手のひら、半黒＝側面、黒＝手の甲。
4. **プレーンの使い分け**: 隙間なし＝垂直（壁面）、隙間あり＝水平（床面）。

これらの基本を頭に入れたら、次は手がどのように「動く」か、そして相手や物にどのように「触れる」かを表す**「接触と動き」**の記号に進みましょう！
